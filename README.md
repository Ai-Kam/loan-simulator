# ローンシミュレータ

ブラウザだけで動く住宅購入・住宅ローンシミュレータです。`index.html` を開くと、ローン、前提推移、購入タイミング、購入後キャッシュフローを同じ設定で切り替えて確認できます。

## ブラウザ版

`index.html` をブラウザで開いてください。入力値を変えると自動で再計算されます。設定はURLの `#state=...` に保存されるため、同じページを複数タブで開いてもタブ間で設定は混ざりません。

上部のタブで次を切り替えます。

- ローン: 借入額、借入期間、金利シナリオから、残高推移、毎月返済額、支払利息を確認
- 前提推移: 家賃、住宅価値、住居費・貯蓄合計予算の推移を手入力または過去型シナリオで設定
- 購入タイミング: 現在金融資産、家賃、住宅価格、頭金比率、住居費・貯蓄合計予算、前提推移、税金・維持費・売買費用から、金融的に購入条件を満たす時期と純資産差を確認
- 購入後キャッシュフロー: 指定した購入年で購入した場合の月々支払い、所有維持費、投資余力、残債、純資産推移を確認

`buy_simulator.html` は互換用の入口で、統合版の購入タイミング画面へ移動します。

変動金利は常に次の前提で計算します。

- 5年ルールあり: 月返済額の見直しは5年ごと
- 125%ルールあり: 見直し後の月返済額は直前返済額の125%まで
- 未払利息あり: 月利息が返済額を超えた場合、差額を未払利息として残す

選択できる金利シナリオ:

- 手入力
- 短プラ連動（過去変化幅）
- 現在金利据え置き
- 現在金利 +1%
- 現在金利 +2%
- 現在金利 +3%
- 過去高金利ストレス 8.5%

短プラ連動シナリオは、現在入力中の適用金利を起点に、主要行短期プライムレートで見られた過去の変化幅を重ねる簡易シナリオです。実際の店頭基準金利、優遇幅、適用金利を自動取得するものではありません。

手入力では、金利を「年利」と「継続年数」のセットで指定します。

| 年利 | 継続年数 |
| ---: | ---: |
| 0.7% | 5年 |
| 0.8% | 10年 |
| 1.0% | 20年 |

借入期間より金利期間の合計が短い場合は、最後の金利が残期間に継続されます。借入期間より長い場合は、借入期間で切り詰めます。

できること:

- 左軸にローン残高、右軸に月返済額を表示
- グラフに月返済額と支払利息を表示
- 未払利息を年次・月次明細に表示
- 購入タイミングを経済性、必要資金、純資産差で比較
- 指定した購入年の購入後キャッシュフローを月次・年次で表示
- 表示中の画面に応じたCSVを保存

保存・生成されるファイルにも著作権表記を含めます。

- HTML: ページ下部のフッターとHTMLコメント
- CSV: 先頭コメント行

## Python版

Python標準ライブラリだけで動くCLI版もあります。CLI版も5年ルール、125%ルール、未払利息を反映します。

```powershell
python loan_simulator.py --principal 35000000 --term-years 35 --rate-periods 0.7:5,0.8:10,1.0:20
```

出力:

- `loan_simulation.html`: 残高推移、月返済額、年次サマリー、月次明細
- `loan_schedule.csv`: 月次明細CSV

## 計算ルール

- 元利均等返済です。
- 金利は年利として入力し、月利に換算します。
- 金利は年単位で変化します。
- 月返済額は5年ごとに再計算し、増加額は前回返済額の125%を上限にします。
- 月利息が返済額を超える場合、元金は減らさず、差額を未払利息として記録します。
- 繰上返済、手数料、保証料、ボーナス返済は含めていません。
